链路 D

searchScope.ts:15-31 的 5 个 scope 里，body / references 不走书目 haystack。App.tsx 切到 RefsView，250ms 防抖后走 refs:search；refsindex.ts 只读每篇 PDF 末尾最多 20 页，把 References 之后的文本存进独立缓存。匹配与切片段都在 RefEntry.hay 这份归一化副本上，İ 不会让偏移整体错位。

链路 E

7架构评估：优势与代价

优势 1 · 依赖方向被编译配置强制执行shared/ 零反向依赖；主进程复用 src/lib/ 必须先进白名单，而该工程 lib 只有 ES2022。把 document 带进来立刻编译失败。
优势 2 · 单测地基e419fda 一次引入 pathPolicy.ts + 3561 行纯 Node 单测；tests/main-ipc-*.test.ts 捕获 ipcMain.handle 后直接调用 channel，测的是「channel 回答什么」而非「源码有没有那一行」。
优势 3 · 信任边界收在一处提交信息原话：Context isolation isolates code, it does not validate payloads。四个校验函数平台参数可注入，49 个安全用例可在任意 runner 验证 Windows 路径语义。
优势 4 · 一份规则有差分回归兜底ab086b5 下沉页数预算时，在 smoke 里写了 190 个输入的旧规则逐值差分断言，并单独证明旧的两条规则确实会不一致。
代价 1 · 两个高耦合区间未拆完App.tsx 2804 行仍持有 setLib 状态簇与键盘导航；smoke.ts 11798 行仍有两段 UI 驱动链。已被 HANDOFF.md 第 9 节主动登记为技术债。
代价 2 · 五份 JSON 无 schema 版本与迁移结构校验失败一律当成「无缓存」，随后一次写入会覆盖它（HANDOFF.md:701-702）。用「宁可重建」换简单，代价是损坏现场零保留。
代价 3 · 原子写不是并发安全的临时名固定 <file>.tmp；靠主线程串行 + 自检拒绝第二实例兜底。HANDOFF.md:679-681 明写「不要拿去给多进程场景用」。
代价 4 · 源码串断言的维护成本smoke.ts:11402-11404 守护两处刻意例外；重构时须同步校正断言且不放宽判据，把「改代码」和「改约定」绑成一件事。
代价 5 · 冒烟不能进 CIsmoke 需要真实库、真实 PDF 和真正显示的窗口，托管 runner 给不出诚实的帧耗时。

8结论与结构边界

分层把「云端只是同步源、磁盘才是真相」翻译成可执行的结构：领域层产生提议，基础层裁决，协议层挡住不可信输入，纯规则层因无 DOM 可被三端共用与穷举。第二套索引与多标签没有让规则重新分裂。

已落实的结构约束代码证据
检索归一化只有一份，书目 / 参考文献 / 篇内查找 / 保存搜索共用searchScope.ts:45、usePdfFind.ts、refsindex.ts:382
两套索引共用文件判定 / 片段 / 进度；全文表只读规则下沉shared/indexedFileRules.ts:33,52,70、shared/fulltextRules.ts:48-102
近似匹配借用原文词的位置，不改语料与偏移searchMatch.ts:105,151,167、fulltext.ts:915
合并只补空缺字段、批量预算具名化，均为纯规则并配差分测试mergeFields.ts、budgets.ts、tests/*-rules.test.ts

剩余的技术债按「改动会碰到哪道门禁」排序

边界证据为什么还没动
五份 JSON 无 schema 版本与迁移store.ts:36-154 五处手写校验，失败一律当「无缓存」会改落盘格式与启动读取路径，需要先定损坏保留策略
IPC 失败形态不统一ipc/library.ts / ipc/refs.ts 返回 {error}，ipc/docs.ts / ipc/marks.ts 直接 reject渲染层两种形态都要处理，改包装要逐个 channel 配行为测试
两个索引的 worker 定位 / 超时竞速 / 清理仍各一份fulltext.ts:33-60 对 refsindex.ts:119-143pdf.js worker 生命周期被冒烟源码串断言守着，抽之前要先给断言换判据
具名失败门只能扩到已登记的文件smoke.ts:5824-5852 统计 6 个 ignoreFailure + 6 个 reportFailure新增 reason 而不改计数门禁会让冒烟变红；是判据约束，不是能力约束
不在 CI 的那一层smoke 需要真实库、真实 PDF 和真正显示的窗口，托管 runner 给不出诚实的帧耗时；App.tsx 剩余状态簇与 fulltext.ts 写入状态机仍主要靠它守着。
