# Mendeley NG 优化重构说明

> **日期**：2026-11-16
> **依据**：`mendeley-ng架构实现分析.md`、`mendeley-ng架构演化分析.md`、`mendeley-ng第一性原理与设计巧思分析.md` 三份报告里带代码证据的结论
> **原则**：不重写架构。分析显示这套分层本身是成立的，问题是「一份规则的纪律还没铺满所有调用点」（报告三 §5.5）。因此本轮只做五类事：删掉没有归属的攻击面与死代码、把漂移的调用点接回唯一规则、把故障显式化、给未覆盖的纯逻辑补单测、把重复的构建脚本收成一处。
> **方法纪律**：遵守 `HANDOFF.md` §4「测试纪律」——抽共享规则前把旧表达式逐行抄进测试、对大批量输入逐值比，并单独证明退化差异真实存在；源码串断言随产品代码一起校正，不放宽判据。

## 2. 为什么这些改动是安全的

- **1/2/3 是纯删除**：`pdf:read` 的 channel 名在 preload 的 `Api`、`src/global.d.ts`、冒烟里都不存在；11 个 `export` 去掉后若真有跨文件引用，两个 tsconfig 会立刻报 TS2305。`PDF_NAME_FIELDS` 全仓只有声明一行。
- **4/6 遵守项目自己的差分纪律**：`tests/refactor-2026-11-16.test.ts` 把旧表达式逐行抄进测试，对 600+ 个输入逐值比对；归一化那条还单独证明「双空格输入下旧规则与新规则确实不同」，符合 `HANDOFF.md:300-301`「并单独证明退化差异真实存在」。折叠空白是 `HANDOFF.md:616-621` 已写明的有意放宽，不是悄悄改变语义。
- **5 是修一个可复现的缺陷**：测试先断言 `markAll('Deep Learning', 'deep  learning')` 没有任何 hit，再断言改用 `normaliseQuery` 后有 hit——即探测器先证明自己找得到问题。
- **7 只加了两行错误处理**，且 `live` 守卫原本就在作用域里；`{error}` 形态的分支此前已存在，这次只补上「直接 reject」这一种失败形态。
- **8/9 是逐字搬移**：`verify-build.mjs` 保留了原 `node -e` 的每一条判据（chunk 存在、`node --check`、worker > 100 KB、`index.js` 引用的 chunk 存在），只额外补了 preload/renderer 与 `build`/`dist` 接线两项；`scripts/start.mjs` 的 `--smoke` 仍用 `??=` 保留原语义，`demo.mjs` 仍无条件覆盖自己的环境变量。
- **11 只加测试，不改产品代码**；新增的两个 `src/lib` 文件补进 `tsconfig.node.json` 白名单，符合 `HANDOFF.md:476-478`。

## 3. 验证结果

按 `HANDOFF.md` §2 的顺序跑，不跳步：

| 门禁 | 结果 |
| --- | --- |
| `npm run typecheck` | 通过（两个 tsconfig 都过了） |
| `npm test` | **550 个用例全绿**（基线 519 + 新增 31）；16 个测试文件 |
| `npm run build` | 通过，三段产物 + `pdf.worker.mjs` |
| `npm run verify:build` | `build artifacts OK`（chunk / worker / preload / renderer / build-dist 接线） |
| `node --check scripts/*.mjs` | 全部 9 个脚本通过 |
| `npm run smoke -- --no-sync` | 见下方「冒烟结果」 |

**冒烟结果**：基于真实库与真实 PDF 跑完，**685 PASS / 0 FAIL**，末行 `all checks passed`，与改动前的基线断言数一致。日志末尾 `config put back` 表明配置与 `annotations.json` 已按文件快照恢复（`HANDOFF.md:172-175`）。

> 期间有一次 `npm test` 因临时目录 `EPERM` 少收集了一个测试文件（WorkBuddy 文件系统代理的偶发错误），立即原样重跑得到 16/16 文件、550/550 用例全绿；不是产品代码问题。

## 4. 没有做的事（以及为什么）

分析报告里还列了几项，**本轮刻意不动**：

| 未做 | 原因 |
| --- | --- |
| 拆 `src/App.tsx`（2720 行）与 `electron/main/smoke.ts`（11712 行） | `HANDOFF.md:682-690` 已登记：拆它们要连带重排冒烟里大量 UI 驱动与接线断言，必须先补行为测试。属于下一轮，不是这一轮能顺手做完的。 |

| 把 `token.json` 迁到 `safeStorage` | `HANDOFF.md:676-678`：要同时兼容脚本写的旧文件、导入的 token 与回退路径，没有迁移就改会「莫名要求重新授权」。 |
